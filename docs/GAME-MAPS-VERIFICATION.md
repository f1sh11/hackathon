# 卡通游戏界面与地图验证

验证日期：2026-10-22。仍为移动网页 App；后端继续使用 .NET 与 PostgreSQL。

## 已验证

- 原创橙色背包伙伴、气泡问答、立体按钮、角色卡、行程及四栏底部导航已统一为卡通风格。
- 完整六问真实提交，生成固定只读画像；没有调分滑块。
- 创建任务、逐站 HP / 预算、轻松重规划及原版本保留。
- 无画像时可以打开地图，自由探索示例地标。
- 地图支持点击编号、键盘选点和站点按钮；切换步行 / 驾车 / 公交保留当前目的地。
- 从行程详情进入地图带入当前版本：在已有 V2 时查看 V1，地图仍打开 V1；切换 V2 后站点由 5 个变为 4 个。
- 已实际打开 Apple Maps 的 Circular Quay 地点页，并确认地点名称、悉尼地址及坐标信息。
- 泛化简餐活动没有直接导航链接，先搜索具体地点。
- 返程地址为空时禁用导航；填写公开示例地址 Central Station 后，链接目的地与输入一致。
- 一分钟无解任务在地图页显示无路线，画布数量为 0；不会借用其他任务的旧路线。
- 浏览器 320px / 375px / 390px 下无横向溢出。
- TypeScript、生产构建、11 组实际地图 helper 测试通过。
- Docker 部署后，正式本地库的完整画像、原任务 ID 及全部历史版本通过严格快照比对；只更新应用容器。

独立数据库用于浏览器测试，未删除原数据。Apple 地图链接采用官方 URL；App 画布明确是路线示意，没有配置 Maps token 或内嵌 Apple 底图。费用、HP 和行程时间仍为演示估算。
