本地修改，未 commit / push。基于当前 main 的 Koko 整合版本；保留 Apple 地图和已有行程流程。

## 行为

- 恢复绿色按钮、薄荷色卡片、暖白背景；Koko 素材本身的珊瑚色背包保持原样。
- 初始选项给出具体玩法；“换个玩法”轮换绿意慢走、城市故事、街区逛吃并更新灵感内容。接受方向才写入本次 interests，不创建长期记忆。
- 自由输入始终保留。“我想自己说”只聚焦输入框，不发出一条无信息消息。
- “旅行资料”、背包和补充按钮进入同一分步资料页：城市；日期和 1–15 天；1–30 人；AUD 活动预算及每人/全体、每天/全程范围。已知信息预填，从缺失组继续；逐组确认保存。
- 无目的地和无效预算当场提示；有效资料齐全后固定展示生成按钮，无需再进摘要页。旧的全部资料页面留在更多菜单。
- 修正灵感卡城市和本次兴趣显示滞后。
- 实测发现自由聊天“想去歌剧院，不去博物馆”只收到口头确认、未进规划条件；补齐常用明确表达的确定性提取，避免把否定或“想去悉尼”当成必去景点。

## 第二轮：生成阻塞提示、追问联动、单项资料编辑

- 生成阻塞原因独立展示，不再被快捷选项覆盖。非悉尼目的地明确说明支持范围，可修改城市或保留草稿；外币/总旅行费用需要先确认 AUD 活动预算，并直接打开预算编辑。
- 进入规划后按缺失内容提供城市、日期、人数、预算选项；填写已知资料不重复追问。自由文字明确提供旅行事实后直接进入对应下一步，不要求先完成四轮玩法问答。
- 日期可以留空并继续确认人数和预算；最终生成前仍必须明确日期，不擅自填入今天。
- “预算还没想好，能先选个大概范围吗？”明确停用原金额，提供 60/120 AUD 每人每天档位和自定义入口；档位不是已核实花费。选择金额只影响本次旅行，原目的地、日期、人数及必去/避开要求保留。
- 旅行资料总览逐项编辑，日期与天数作为相关组；住宿/起点、必去、避开、同行需求单独编辑。取消不保存当前修改；逐项保存后保持其他值，并更新 Koko 的回复与下一步选项。
- 将弹层路由改为携带目标字段，修复首次点击单项入口误开总览的问题。旅行灵感默认折叠，避免大卡片覆盖最新回复和规划摘要。
