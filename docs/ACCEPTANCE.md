# 第一版验收

## 产品范围

单个本地使用者、悉尼、一日游。问答生成固定画像；任务保存到 PostgreSQL；后端规划器生成完整行程；可查看历史和生成轻松版。不包含账号、多用户、真实预订、实时地图、天气、自然语言理解或媒体上传。

## 手动试用

1. 打开本地应用，完成六题，看到自动生成的雷达图。页面没有调分控件。
2. 创建海港主题任务：09:00–18:00、A$120、HP100。
3. 检查时间线包含返程；费用、步行和 HP 都有对应条目。
4. 刷新并从任务列表重新打开，内容仍在。
5. 生成轻松版，检查版本 V1、V2 都能查看，画像没有变化。
6. 将截止时间缩至十分钟，应该得到无可行解及解释，而非空白或虚假的成功。
7. 试低预算、低精力、晚间出发、无效时间。
8. 重启应用与数据库容器后，重开已保存任务。

## 自动验证

- `dotnet run --project tests/Roam.Core.Tests`：纯 C# 规划器与随机约束测试。
- `node scripts/smoke.mjs`：对正在运行的 .NET + PostgreSQL 做真实 HTTP 验收。
- `.github/workflows/ci.yml`：在 GitHub 上安装依赖、构建前后端、运行核心测试、启动 Compose 并执行 HTTP 验收。

写好了工作流不代表 GitHub 已跑绿。尚未连接远端仓库时，只能报告已实际完成的本地验证。

## 数据含义

地点名称部分借用悉尼地标，但坐标网格、开放时间、费用、转场、步行和 HP 全部为示例数据。日期随任务保存；当前不处理节假日与当日营业变更。未知开放时段的地点排除。备注仅保存，不用于改变计划。HP 是产品估算，不是健康测量。
