# 手机 App 界面验证

验证日期：2026-10-22。此版本是移动网页 App 界面，使用 .NET 与 PostgreSQL，未生成原生安装包。

## 已验证

- 真实浏览器逐题完成六问：未选择不能继续，返回上一题保留答案，完成后通过 API 固定保存画像。
- 雷达只展示后端派生画像，没有分数滑块或编辑入口。
- 创建任务后获得真实后端生成的完整行程；每站展示费用、HP 变化、剩余 HP 和累计扣费后的预算。
- 演示任务起始 HP 100、预算 A$120，初始方案结束 HP 70、花费 A$24、14:29 返回；最后一站剩余预算 A$96，与总额一致。
- 轻松版新增 V2；仍可切回 V1，刷新后任务和历史版本保留。
- 320px、375px、390px 页面无横向溢出；底部导航有安全区和正文底部留白。
- 修复日期/时间输入即时同步问题：修改返回时间后，再修改预算，时间不会恢复旧值。
- 正式构建中提交 09:00–09:01 的任务，正确保存为无可行解并显示时间不足，不展示成功行程。
- TypeScript 与前端生产构建通过。
- Docker 更新应用容器后，原画像、原行程及其两个版本保持一致；数据库容器未重建。
- 应用健康检查正常，manifest 可读取；没有配置离线缓存或外部旅行 API。

浏览器流程使用独立测试数据库，保留原有本地使用数据。上述时间、费用、路线和 HP 均为示例估算。
