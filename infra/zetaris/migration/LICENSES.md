# 公開來源與署名

本套件保留每筆 payload 的來源、版本／擷取時間、署名及授權資訊。資料快照不代表即時營業、價格、評論或熱門度。

- Overture Places：資料中的 sourceLicense / licenses / attribution / release 必須一起保留；本次來源標示 CDLA-Permissive-2.0。來源：https://docs.overturemaps.org/attribution/ 與 https://cdla.dev/permissive-2-0/
- OpenStreetMap：ODbL 1.0，保留 © OpenStreetMap contributors 與來源連結；公開提供衍生資料庫前，依實際組合方式確認署名、授權及提供資料庫的義務。https://www.openstreetmap.org/copyright
- Wikivoyage：保留 guide.sourceUrl（含 revision）、attribution、license、licenseUrl；本次指南標示 CC BY-SA 4.0。https://en.wikivoyage.org/wiki/Wikivoyage:Copyleft
- Wikimedia Commons：照片只有 URL 與中繼資料，沒有打包圖片原檔。各照片授權與作者分別保存，不能把整份照片集合視為單一授權。https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
- 既有 8 個行程候選是本專案示範資料，時間／費用等仍是規劃假設。
- 天氣沒有匯出記錄；只提供 Open-Meteo REST 設定。正式使用前確認服務方案與署名要求：https://open-meteo.com/en/terms

公開資料仍可能含商家公開電話、地址及作者姓名；此包並非個資匿名化工具。打包檢查會拒絕常見私密欄位，無法判斷任意文字中所有秘密，分享前仍須確認資料來源。
